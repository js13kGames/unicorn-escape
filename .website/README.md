Unicorn Escape is a tiny metroidvania-style adventure about a unicorn who has fallen into a mysterious cave.

Explore the cave by bouncing, flying, and creating temporary rainbow platforms. Find the missing colours of the rainbow to unlock new abilities, opening up new routes and helping you reach places that seemed impossible before.

There are no enemies and no fighting. It’s all about exploration, movement, finding secrets, and figuring out how to escape.

The game was made using [BeepMicro](https://github.com/BeepMini/BeepMicro), my tiny JavaScript game engine for making very small browser games.
